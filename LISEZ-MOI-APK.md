# Xtream Studio IPTV — Dossier `appgen` pour GitHub / Android APK

Ce dossier **`appgen`** contient l'intégralité des fichiers prêts à être copiés dans un dépôt GitHub pour générer automatiquement votre fichier **`.APK`** Android & Box TV (Mi Box TV).

## Générer l'APK gratuitement sur GitHub :
1. Créez un nouveau dépôt sur [GitHub.com](https://github.com/new) et copiez-y le contenu de ce dossier `appgen`.
2. Ouvrez l'onglet **Actions** de votre dépôt GitHub.
3. Le workflow **Build Xtream Studio Android APK** compile automatiquement le fichier **`app-debug.apk`** prêt à installer sur votre Mi Box TV ou téléphone Android.
